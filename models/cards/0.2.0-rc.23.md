## Analysis

<!-- modelgate:analysis:start -->
This candidate replaces the feature `region_score` with `txn_velocity`. The model family, output schema and hyperparameters are unchanged, so the computed bump is minor. The champion's latest nightly drift check raised an alert (PSI of utilization is 0.2140, limit 0.1), but `utilization` is a feature in both models and the bump reasons do not mention it, so drift is not shown to be the reason for this change.

Against champion 0.1.0, overall AUC rose from 0.8397 to 0.8558 (+0.0161). The Brier score improved from 0.1458 to 0.1384 (-0.0074). Per segment, AUC moved by more than 0.01 in all three: A +0.0400, B +0.0332, and C -0.1360.

One rule failed: `slice_gap`. The gap between the best segment AUC (A, 0.8765) and the worst (C, 0.7107) is 0.1658, against a limit of 0.0500. The other five rules passed. The most likely cause is that `txn_velocity` helps segments A and B but is a weaker signal for segment C, or that `region_score` carried information that mattered for C. The report does not confirm this.

Carbon: SCI is 0.038 gCO2e per candidate, which is 0.024 gCO2e per 0.01 AUC gained, or 0.42 AUC gained per gCO2e. The carbon rule passed.

Recommendation: a reviewer should decide whether a better overall model is acceptable when segment C (2331 holdout rows, 12% of the data) gets worse by 0.1360 AUC. Check how `txn_velocity` behaves for segment C, and whether a model that keeps `region_score` alongside `txn_velocity` closes the gap. If segment C matters in production, do not promote until the gap is within 0.0500.

A minor bump fits the feature change.
